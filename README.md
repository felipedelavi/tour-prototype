# Rivière Doré — tour interativo

Tour 3D do Rivière Doré (RDO Home Studios), produzido pela Boltz Films. Site estático: three.js + Google Photorealistic 3D Tiles.

Publicação: Vercel importa este repositório sem build; cada push na `main` publica.

A chave do Google Maps está em `index.html`; mantenha-a restrita ao domínio publicado.
